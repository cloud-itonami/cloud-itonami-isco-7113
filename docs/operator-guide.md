# Operator Guide

## First Deployment

1. Define the workshop's registered-and-verified craftsperson roster
   and task-scheduling process.
2. Define safety-concern categories (dust exposure, blade/tool hazard,
   material-handling strain) and the escalation target (the workshop
   safety officer).
3. Run synthetic operating cases (work-record logging, crew
   scheduling, supply-order coordination, safety-concern flagging).
4. Enable human-reviewed sign-off for `:high`/`:safety-critical`
   actions — every safety-concern flag and every over-threshold supply
   order.
5. Measure operating outcomes and audit coverage.

## Minimum Production Controls

- registered AND independently verified craftsperson/workshop
  provenance for all operating records
- safety-critical escalation path to a human workshop safety officer
- human review for over-ceiling crew scheduling and over-threshold
  procurement
- audit export for all gated actions
- no code path by which the actor can finalize a stone-cutting/
  carving-execution decision or override the workshop safety officer's
  judgment

## Certification

Certified operators must prove that the governor gates every
safety-critical action, that safety concerns always escalate to a
human workshop safety officer, and that the actor never finalizes a
stone-cutting/carving-execution decision itself.
